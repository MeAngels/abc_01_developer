## How work

Markdown has a list of styles that can apply, like:

+ Heading
+ List
+ Text style
+ Table
+ Others a lot more

These was the specific way to apply, but markdown work well with html tag too.

### Headings \#

+ \# Heading 1
+ \## Heading 2
+ \### Heading 3
+ \#### Heading 4
+ \##### Heading 5
+ \###### Heading 6
+ \####### Heading 7

### Styles

| Style                 | How to do                 |
| ---                   | ---                      |
| **bold**              | `**bold**`    |
| *italic*              | `*italic*`                |
| ~~strikethrough~~     | `~~strikethrough~~`       |

> Blockquote
>
>> Multiblock

### List: * | + | -

* Item 1
* Item 2
    * Sub-item 2.1
* Item 3
    * Sub-item 3.1
        * Sub-sub-item 3.1.1
* Item 4
    + sub-item 4.1
        - sub-item 4.1.1

1. Ordered List
2. Ordered List

- [x] Completed task
- [ ] Todo task

### Table

| Column 1  |   Column 2    | Column3   |
|   :-:     |   -:          |   :-      |
|   Row 1   |   Row 2       |   Row 3   |

()  parenthesis
[]  square brackets
{}  curly braces
#   hash mark
!   exclamation mark
<>  angle brackets
