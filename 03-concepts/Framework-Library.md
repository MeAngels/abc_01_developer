
## naming convention

* camelCase
    + first letter is lower case, then first letter of each word is capitalized
    + functions

* PascalCase
    + each first letter of word is capitalized
    + class

* snake_case
    + separate using underscore (_)
    + variables

* kebab-case
    + separate using hyphen -
    + Use more in url

## Framework vs Library

+ Framework: are complete estructure, like: express, angular, nextjs, ...

+ Library: small piece resuable code, you decide how to build, like: jquery, lodash, react, redux, ...
