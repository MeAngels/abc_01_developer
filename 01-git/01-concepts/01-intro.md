
## What is version management

+ Effective tool for version management
+ Allow navigate between changes and return to a previous state
+ Allow a better way for a team work on a project
    + A group can work with a copy of the file (branch) and merge the changes later

## Task

1. Create
2. Save
3. Edit and Save
4. Edit and Save again
5. Compare files
6. Share
7. Others Edit and Save

## Why

+ Manage each version of the project
+ Know what changed on each version
+ Know why something was modified
+ Know who modified and when
+ Compare changes
+ Undo changes
+ Avoid overload of changes
